# Data Flow Diagram (DFD) - ระบบบริหารจัดการโครงการ

## ภาพรวม

Data Flow Diagram แสดงการไหลของข้อมูลในระบบบริหารจัดการโครงการ แบ่งเป็น 3 ระดับ:

- **Context Diagram (ระดับ 0)**: ภาพรวมของระบบทั้งหมด
- **Level 1 DFD**: กระบวนการหลักของระบบ
- **Level 2 DFD**: รายละเอียดของแต่ละกระบวนการ

---

## สัญลักษณ์ที่ใช้ใน DFD

| สัญลักษณ์       | ความหมาย                                    | ตัวอย่าง                           |
| --------------- | ------------------------------------------- | ---------------------------------- |
| วงรี            | External Entity (ผู้มีส่วนเกี่ยวข้องภายนอก) | พนักงาน, ผู้จัดการ                 |
| สี่เหลี่ยมมุมมน | Process (กระบวนการ)                         | จัดการผู้ใช้งาน, วางแผนกิจกรรม     |
| ทรงกระบอก       | Data Store (ที่เก็บข้อมูล)                  | ฐานข้อมูลพนักงาน, ฐานข้อมูลโครงการ |
| ลูกศร           | Data Flow (การไหลของข้อมูล)                 | ข้อมูลเข้า-ออก                     |
| ลูกศรเส้นประ    | Control Flow (การควบคุม)                    | การเชื่อมโยงระหว่างกระบวนการ       |

## การไหลของข้อมูลหลัก

### 1. การวางแผนกิจกรรม

```
พนักงาน → สร้างแผนกิจกรรม → บันทึกในฐานข้อมูล → เพิ่มผู้เข้าร่วม → แนบเอกสาร → บันทึกหมายเหตุ → แจ้งเตือนผู้เกี่ยวข้อง
```

### 2. การเช็คอิน-เช็คเอาท์

```
พนักงาน → กดเช็คอิน → บันทึกตำแหน่ง GPS → ถ่ายรูป → บันทึกข้อมูล → ทำงาน → กดเช็คเอาท์ → คำนวณเวลา → สรุปรายงาน
```

### 3. การจัดการโครงการ

```
ผู้จัดการ → สร้างโครงการ → เชื่อมโยงองค์กร → เพิ่มผู้ติดต่อ → กำหนดกิจกรรม → ติดตามความคืบหน้า → สร้างรายงาน
```

### 4. การจัดการเอกสาร

```
ผู้ใช้งาน → อัพโหลดไฟล์ → ตรวจสอบประเภท → บันทึกในระบบ → เชื่อมโยงกับกิจกรรม/โครงการ → แสดงผลให้ผู้ใช้
```

### 5. ระบบอีเมลอัตโนมัติ

```
ผู้ดูแลระบบ → ตั้งค่า SMTP → สร้างเทมเพลต → กำหนดเวลาส่ง → Hangfire ทริกเกอร์ → ส่งอีเมล → บันทึก Log → สร้างรายงาน
```

### 6. การแจ้งเตือนแบบ Push

```
พนักงาน → สมัครรับการแจ้งเตือน → บันทึก Subscription → เกิดเหตุการณ์ → ส่ง Push Notification → แสดงการแจ้งเตือนบนอุปกรณ์
```

## หมายเหตุ

- DFD แสดงการไหลของข้อมูลเท่านั้น ไม่แสดงลำดับเวลาหรือการตัดสินใจ
- ทุกกระบวนการต้องมีข้อมูลเข้าและข้อมูลออกอย่างน้อย 1 รายการ
- Data Store แสดงถึงที่เก็บข้อมูลถาวร (ฐานข้อมูล)
- External Entity คือผู้ใช้งานหรือระบบภายนอกที่โต้ตอบกับระบบ
